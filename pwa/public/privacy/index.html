Privacy Policy

Sea Haven collects nothing. There is no account, no sign-in, no analytics, no advertising, and no server of ours anywhere that knows you played.

Applies to the web game and to any app built from it. Last updated 2026-09-09.

What the game stores

The game remembers a few things so that it is still the game you left. All of it is held by your own browser or app, on your own device, in ordinary local storage:

  • Your settings, once there are settings to keep.
  • Your best times, once there is a board to keep them on.

None of it is transmitted. Clearing the site data in your browser, or deleting the app, deletes all of it, and there is no copy elsewhere to restore it from.

What the game sends

Nothing. The web version loads the game's own files from its own address once, then runs offline. The only connection you can cause is a link you press yourself — the source repository, or a credit — which opens in your own browser and is then between you and that site.

Children

The game is suitable for a general audience and collects no personal information from anybody, of any age. There is nothing to buy inside it and no way to communicate with another player through it.

Hosting

The web version is served by GitHub Pages. Like any web server, it sees the requests that fetch the page. We neither receive nor keep those logs, and we run no other service that the game talks to.

Changes

If a future version of the game ever gains something that does leave your device, this page changes in the same release that adds it.
