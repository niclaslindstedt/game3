The game no longer opens straight onto the water. An arcade attract card holds the house's name while the first shore is built, then asks for a press; behind it is a main menu with START and OPTIONS, painted over a sea the bot is already riding — the water never stops. START stands the run up behind a loading card that counts the work in phases instead of pretending to know the seconds, and Escape leaves a run for the menu again. OPTIONS carries the craft, the camera a run opens on and whether the HUD is drawn, remembered between visits; the arrow keys walk any card and Escape backs out of one.

Holding START for seven seconds — the row fills and says so on the way — lets out a DEVELOPER page: the seed, a wind and a sea to override the level's own, the staged moments, the frame cost, and a COPY REPRO LINK that writes the lot back out as a URL anyone can open.
