type: Fixed
title: The countdown is back on every run
---

A staged SCENE — the developer link's `?scene=`, used by the labs to
photograph a moment — was being kept in stored settings. It has always taken
the lights off the run it stages, which is right for a frame being
photographed; kept, it re-staged every ride afterwards, so once the
developer page had been unlocked every run came up reading GO! with no
count in front of it and no row on any card to take the scene off again. A
scene now lasts as long as the URL that asks for it, and a browser that
already stored one heals on its next visit.

A staged moment also no longer claims lights it never ran: its rules say it
has none, so the HUD says nothing rather than announcing a GO.
