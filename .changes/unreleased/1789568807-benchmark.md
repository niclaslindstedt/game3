The developer page can now time this machine: **BENCHMARK** takes the canvas for thirty seconds and draws a fixed piece of riding — twelve craft off one green on a pinned shore under a pinned sky with four metres of swell running under it, the same race every run — as fast as the machine will draw it, and reports an INDEX where 100 is drawing the race in the time it takes to ride, on a live graph rather than a counter so a machine that stumbles halfway leaves a kink that one figure at the end would have hidden. OPTIONS ▸ VIDEO is the one thing it deliberately does not pin, which is the whole use of it — run it, move a picture row, run it again, and the difference is what that row costs here — and COPY DEBUG REPORT writes the run out as text, with what a frame cost the renderer, what was standing in the scene, and every reading's draw calls sitting in the same row as its frame rate.
