title: A finished run always says so, and a developer's overrides stop following you around
---

The end-of-run plate is back on every run. The test that keeps a doctored
figure out of the record book was written as a single early return, so it
also swallowed the plate: anybody carrying one of the developer page's
override rows — a staged scene, a wind or a sea set by hand — finished every
run in every mode to silence, which reads as the game hanging. A rider who
crosses the line now always gets the plate; it simply claims nothing and
never says NEW BEST on a run the game will not vouch for.

Those three rows are also no longer remembered. Each is set by a link alone,
each silently re-stages or re-weathers every run afterwards, and none has a
row on any card to switch it off — so they now last as long as the URL that
asks for them, a browser already carrying one heals on its next visit, and
RESTORE DEFAULTS clears them. The frame-cost readout, which has its own knob
on the page, is remembered as before.
