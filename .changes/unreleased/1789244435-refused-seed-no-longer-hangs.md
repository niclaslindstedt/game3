---
type: Fixed
title: A seed with no coast on it no longer hangs the game
---

The level generator refuses a seed it cannot build a clean shore on — about one in a hundred, and more often on the mangrove coast than the taiga. The game now says so: the loading card reports NO COAST AT THIS SEED and hands you back to the start card to pick another one. Before, the refusal froze the game on BUILDING THE SHORE with the mark still turning and no way off it, and a refused seed carried in a link or left in the stored settings stopped the game loading at all.
