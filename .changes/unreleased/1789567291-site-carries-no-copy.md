---
type: Removed
title: The website no longer describes the game
---

The page the browser loads is now the game and nothing else. The static description that sat under it — what the game is, how it plays, the four craft, the controls, how to install it — is gone, along with the share card a pasted link used to unfurl into and the metadata that fed both. The site tells crawlers not to index it, ships no sitemap and no `llms.txt`, and the privacy and support pages stay reachable for a store to fetch without being a way in from a search result. Nothing about playing it changes: the game boots the same, installs the same and runs offline the same.
