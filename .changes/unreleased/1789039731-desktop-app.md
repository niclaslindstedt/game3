type: Added
title: The desktop app
---

Sea Haven runs as a desktop app on Windows, macOS and Linux: a thin Tauri shell around the same built website, bundled inside it and served from a private scheme, so it plays offline and keeps its settings between launches. The window remembers its size and place, F11 takes it fullscreen, links out open in your own browser, and on macOS there is a real menu bar whose rows press keys the game already has. Every release now carries an installer per platform.
