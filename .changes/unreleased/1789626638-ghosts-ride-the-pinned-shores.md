type: Changed
title: The ghost rides the pinned shores, alone
---

The ghost now follows the three measured modes onto the campaign's twelve
pinned levels: a TRICKS run and a TIME TRIAL down one of them put your best
run on that level back on the water, whichever way you reached it. What no
longer keeps one is a run with a FIELD on it — a race, and the campaign's own
rungs — because a rival's wake is real water the hull reads, so that run
cannot be ridden again without riding all eleven rivals again — ride one back
without them and the craft is metres off its own line inside ten seconds. Tapes
for water the game no longer has are swept the next time it starts.
