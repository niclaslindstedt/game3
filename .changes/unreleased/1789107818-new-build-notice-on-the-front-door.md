---
type: Changed
title: The new-build notice now stands on the front door too
---

The mark that says a newer build is waiting used to appear only over a run, which is the surface a player is least likely to be on when a deploy lands. It now stands in the same top-right corner, in the same chrome and with the same two presses, over the main menu as well — above the card's wash, so it can actually be pressed. The attract and loading cards still cover it: those are the app covering its own screen.
