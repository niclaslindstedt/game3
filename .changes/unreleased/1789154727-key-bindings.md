title: Key bindings, and S on the brake
---

Which key does what is yours to change. OPTIONS ▸ KEYBOARD lists every action on the craft and every press around a run — press a row, then press the key you want on it. Escape backs out of a row without binding anything, so the way out of every surface in the game stays where it is, and RESET KEYS puts the shipped layout back without touching anything else you have chosen. The page is offered only on a machine with keys, and your bindings are remembered between visits.

The shipped layout moves with it: **S is now the brake and reverse**, beside Space, so the left hand has the whole driving set — W throttle, S brake, A and D steering. Leaning back is the down arrow, and the arrow cluster stays the handlebar it always was.
