---
type: Changed
title: One knob for every setting, and a pause card that carries its own
---

Every settings row in the game is now the same shape: the setting's name on the left, its value on the right between two arrows, and pips under the value saying where on its ladder it stands. OPTIONS was a column of chip rows and switches with a sentence under each of them; it is now two columns of rows under PICTURE, RIDING and HUD, with the explanations moved to one caption bar at the foot that reads whichever row you are looking at — so the whole page fits a laptop window and a phone held upright without scrolling. The start card and the developer page wear the same rows: THE RUN's five skies no longer wrap to a second line, the shore is a seed you can type as well as step, and the answer each row was dealt by the seed is marked both beside the value and on its ladder. THE RUN also takes the width it was wasting — on anything wider than a phone the coast's chart stands beside the rows instead of over them, which costs the card no height at all and buys the chart half again as much of it, so a course can be read off the picture before you ride it.

The pause card no longer opens the options page. It carries the three settings you actually stop mid-run for — the camera, the HUD and the frame rate — as a strip between RESUME and MAIN MENU, and leaves the picture rows to the front door, where the sea behind the card is still moving to judge them against.
