RACE, TRICKS and TIME TRIAL are the first three tiles on the main menu, each with its own mark, instead of a row on the card behind it. Which game is being played decides what the shore is for, so it is asked before the shore is — and the start card that follows is titled with the game it is setting up. GALLERY and OPTIONS stand under them, quietly.
