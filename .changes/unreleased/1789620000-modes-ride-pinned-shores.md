RACE, TRICKS and TIME TRIAL now ride the campaign's twelve pinned shores instead of a seed you dial. Each of the three opens a LEVEL card — the campaign's own shores and boxes, open wherever the campaign has opened them, showing what the run would be, the day the level pins and your best on it — so two times down the same level are two times down the same water. A tricks run still picks its own LENGTH there. FREE RIDE keeps the start card, and is now the only place a seed, a wind off any quarter and a sea of any size are asked for.
