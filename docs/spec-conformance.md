# Conformance with OSS_GAME_SPEC.md

[`OSS_GAME_SPEC.md`](../OSS_GAME_SPEC.md) at the repository root is this project's governing specification, and the committed copy IS the spec — a verbatim copy of the sibling rally game's, self-contained, amended in a reviewed pull request, with no upstream document to reconcile against and no validator to phone. This page is the other half of that arrangement: **one row per chapter, a verdict, the evidence behind it, and — where the repo falls short — what the gap costs and what closing it would take.**

It exists because a conformance claim with nothing behind it is a badge. The `sync-game-spec` skill walks the spec chapter by chapter and re-dates every row; a sweep that changes no code still updates this file, because a verdict with no date behind it is an opinion.

**This repository is a vertical slice**, and the ledger says so rather than rounding every unbuilt chapter up. Sound, the sky, damage, menus, the campaign, replays, the shells, fauna: each is a placeholder file with a header comment saying what will live there. A chapter whose subject is a placeholder is **not yet built**, with the placeholder path as the evidence — not N/A (the condition WILL apply) and not conformant (nothing is there to conform).

**Verdicts:** ✅ conformant · ◐ partial, with the gap named · ✗ not conformant · ○ not yet built (a placeholder stands where the subject will) · ⊘ deliberate deviation, with the reasoning · — not applicable, with the reason.

_Last walked: 2026-09-09, against spec v1.1.0, at the bootstrap._

## What to do next, in the order it pays

The gaps are not equal. In descending order of value per hour:

1. **§37.1 — prove the input path.** A test over the input manager that a press between two steps reaches the next step; `input.ts` claims it in its header and nothing holds it. Minutes.
