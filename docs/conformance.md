# Conformance

Sea Haven is built to the fleet's game guidelines, and `AGENTS.md` names the
version it follows. This page is the ledger of where the repository
**knowingly falls short** of them: one row per rule, the verdict, the evidence,
and what closing the gap would cost. A rule this page does not name is one the
repository meets; a gap found and not written down here is a bug in this page.

**Verdicts:** ◐ partial, with the gap named · ✗ not met · ⊘ a deliberate
deviation, by owner decision.

A row with no date behind it is an opinion, so every row carries the day it
was last checked against the tree. The closing step of a `maintenance` sweep
walks this table: re-check each row, re-date the ones that still hold, delete
the ones the tree has closed.

| Rule  | Subject                           |  V  | Evidence, and what closing it costs                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | Checked    |
| ----- | --------------------------------- | :-: | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| G3.14 | The developer toolbelt            |  ◐  | The measuring tools parse their flags through the shared framework's `tooling/cli`: `--help` with defaults, exit 2 on an unknown flag, inputs printed beside outputs. `generate-icons` and the framework's `ogf-skill-lessons` and `ogf-*` release bins do not, and exit 0 on a flag they do not know, so a typo there is still silent. Closing it: the last few tools onto `tooling/cli` (the bins in the framework).                                                                                                        | 2026-09-28 |
| G3.15 | Worked examples                   |  ◐  | `examples/seeds.md` is a seed list reproducible by one command. Nobody builds against the game (there is no mod format), so it is reference material rather than an example; it is not its own directory and CI does not exercise it (the sim job does ride the same seeds). Closing it: fold it into `docs/`.                                                                                                                                                                                                                | 2026-09-28 |
| G4.7  | One command per capability        |  ✗  | `make sim`, `make screenshots` and `make icons` exist. **There is no `make store-shots`**: the store screenshot harness is not ported, because its recipes stage frames against this game's own HUD and shores and have to be written for them — storefront work, not a rename. There is no `make bench` (see G10.5), and the assets target is spelled `make icons` and covers only the app mark.                                                                                                                             | 2026-09-28 |
| G6.6  | Slots never share storage         |  ◐  | The manifest's `id`/`scope`/`start_url`/`name` and the service worker's cache id branch per slot. **The storage keys do not**: `sea-haven-settings`, `-records`, `-campaign` and the rest are keyed by origin, so `/preview/` and `/` read and write the same saves. Closing it lands with G13.1's prefix move.                                                                                                                                                                                                               | 2026-09-28 |
| G7.5  | The sequel test                   |  ◐  | The generator can be deleted and the physics, course, bot and sim suites still pass on the synthetic level. The catalog cannot: the rule tests name craft ids (`craft: "skiff"` throughout `craft_test`, `flight_test`, `collision_test`, …), and the generator reads `CRAFT` for R18's ring placement. A fixture craft, and R18 taking its design hulls as parameters, closes it.                                                                                                                                            | 2026-09-28 |
| G7.6  | A narrow startup path             |  ◐  | `App.tsx` reaches the renderer (and through it three.js) through a dynamic import, which keeps it off the first-render path. There is no narrow entry surface: the app imports `@engine` whole to stand a run up.                                                                                                                                                                                                                                                                                                             | 2026-09-28 |
| G8.1  | Catalogs as data                  |  ⊘  | **By owner decision, mirrored from the sibling rally game.** Levels are generated from a seed rather than authored, so the only catalogs are `engine/game/defs/{craft,tuning,fauna}.ts` and `mapgen/{biomes,rules}.ts` — TypeScript consts, not schema-validated data files. The type checker is the schema and a cross-reference is a compile error. Lost: a non-programmer cannot add a craft, and no mod could ship one. The path, when it pays: `defs/` becomes the compiled output of a validated data file per catalog. | 2026-09-28 |
| G8.3  | One identity module               |  ◐  | `pwa/src/identity.ts` holds the name, copy, colours and URLs, and `tests/identity_test.ts` holds every restatement to it. **The storage prefixes and the service-worker cache prefix are not in it**: `sea-haven-*` is a literal in each module that saves something, and in `pwa/src/app-pwa.ts`.                                                                                                                                                                                                                            | 2026-09-28 |
| G8.4  | Ids outlive their content         |  ◐  | Level and craft ids are stable and now reach saves (records per course, the campaign, ghosts), and none has been reused. There is no tombstone list and no loader that could answer one, so retiring an id would silently drop the saves that name it.                                                                                                                                                                                                                                                                        | 2026-09-28 |
| G8.6  | One command per derived asset     |  ◐  | `make icons` writes every web icon from the one authored mark. The phone app's `native/assets/icon.png`, `splash-icon.png` and `favicon.png` are byte-for-byte copies of two of them, put there by hand: nothing regenerates them, so a change to the mark reaches the phone app only if someone remembers. Closing it: `scripts/generate-icons.mjs` writes them too.                                                                                                                                                         | 2026-09-28 |
| G10.2 | The headless simulator            |  ◐  | `make sim` runs the real engine over seeds and the whole roster, prints and takes seeds, tries a `TUNING` change without a rebuild, and runs in CI. Missing: **A/B comparison of two configurations** in one run, and a pass/warn/fail verdict beyond "a craft finished no seed".                                                                                                                                                                                                                                             | 2026-09-28 |
| G10.5 | Benchmarks against a baseline     |  ◐  | `make profile` counts what a frame costs the renderer per scene, and the in-game benchmark measures the machine in hand. There is no recorded baseline to diff against and no steps-per-second benchmark of the engine.                                                                                                                                                                                                                                                                                                       | 2026-09-28 |
| G11.3 | Interface as content              |  ✗  | The HUD and menus are Preact components, not authored content with a schema and stable ids — though every word they show is a key in `pwa/src/game/strings.ts`. With no mod boundary the interface is not required to be content.                                                                                                                                                                                                                                                                                             | 2026-09-28 |
| G11.4 | Audio is content                  |  ◐  | Every sound is authored as data (`pwa/src/game/audio/bank.ts`) and routed from `GameEvent`s by one pure function (`route.ts`); nothing is a file, and `make audition` is the audition surface. Partial because the bank is a TypeScript const rather than a validated data file (the G8.1 deviation), and there is no music yet.                                                                                                                                                                                              | 2026-09-28 |
| G11.6 | Naming rules, written down        |  ◐  | The rule is written where the catalog is — invented names, no real brands, every number inside a class's published range without being any manufacturer's row (`defs/craft.ts`'s header, held by `craft_test`). There is no `docs/naming.md` naming the four carriers a rename moves together.                                                                                                                                                                                                                                | 2026-09-28 |
| G12.1 | Reference device and frame rate   |  ✗  | No reference device and no frame-rate target are written down. `make profile` measures counts, not a target; the water mesh is the known cost and nothing says what phone it must hold 60 on.                                                                                                                                                                                                                                                                                                                                 | 2026-09-28 |
| G12.4 | Accessibility                     |  ◐  | Keyboard, touch and pad input; reduced motion honoured by the splash and the menus. **Not audited: colour-only state** — the HUD's news column and the buoys against the sea lean on hue.                                                                                                                                                                                                                                                                                                                                     | 2026-09-28 |
| G13.1 | Versioned saves                   |  ✗  | The campaign's progress carries a version (`v`), but the records, the settings, the ghosts and the benchmark history are bare JSON with **no version**, and an unreadable payload is silently replaced by an empty book or the defaults rather than failing visibly and staying on disk. Closing it: a version per persisted structure, a read that reports and keeps what it cannot parse, the prefixes moved into `identity.ts` and branched per slot.                                                                      | 2026-09-28 |
| G13.2 | Migration fixtures                |  ✗  | Follows from G13.1: no fixtures captured from a shipped build, and nothing writes a save by write-then-move.                                                                                                                                                                                                                                                                                                                                                                                                                  | 2026-09-28 |
| G14.5 | A rule error ends the run visibly |  ◐  | The URL's `seed`/`craft`/`scene`/`t` and the developer page's copy-repro link stand a run up again, and `output-bridge.ts` keeps the engine's own account of it. Not established: what a thrown rule error does to a run in progress — nothing catches it.                                                                                                                                                                                                                                                                    | 2026-09-28 |
| G14.8 | Text as a keyed catalog           |  ◐  | Every word the HUD and the menus show is a key in `pwa/src/game/strings.ts`, and composed lines are templates. One locale and one table, no pseudo-locale pass over the longest rendering, and a TypeScript const cannot miss a key, so there is no fallback to fail on until the table is data.                                                                                                                                                                                                                              | 2026-09-28 |
| G15.5 | Dependency licences               |  ◐  | `provenance.json` lists every shipped asset, and `make check-licenses` (CI's lint job) holds every npm package in the three lockfiles to an allow-list. **The desktop app's Rust crates are not checked**: `Cargo.lock` records no licence, so covering them needs `cargo metadata` (or a `cargo-deny` step) in the desktop workflow.                                                                                                                                                                                         | 2026-09-28 |
